SyntaxLogicWarning

What it checks

  • Python syntax & indentation errors
  • Java missing semicolons
  • Unclosed brackets and strings
  • Infinite while True loops
  • Loop counters that never change
  • Off-by-one loops (<= length, len+1)
  • Loops counting the wrong way
  • Loops that only run once
  • Lists changed while looping
  • = instead of == in an if
  • Stray ; after if/for/while
  • Strings compared with == in Java
  • is vs ==, == None
  • Mutable default arguments
  • Bare except, unused variables

Sounds: low buzz for syntax errors, double beep for logic errors, soft ping for warnings.

How: Python code is parsed into a syntax tree with Python's ast module and each rule walks the tree. Java is checked with a bracket stack and line patterns. The same review.py also runs from the command line.

Built by Falak Anand in Python and JavaScript, with AI-assisted development. A personal rebuild of an automated code-review tool I made during my software engineering internship at Metabo. This is new code, not the company's. Runs entirely in your browser with Pyodide; your code is never uploaded.
